# Standard-Huffman

A Python implementation of the Huffman coding algorithm for symbol frequency analysis and compression.

## Description
This project implements Huffman coding to compress data by assigning shorter codes to more frequent symbols.

## Features
- character frequency calculation
- Huffman tree generation
- binary code assignment
- compression logic
- decoding support via reverse mapping

## Technologies Used
- Python
- `heapq`
- `json`
- `collections.Counter`

## Prerequisites
- Python 3

## Installation
No package installation is required.

## How to Run
```bash
python StandardHuffman.py
```

## Project Structure
- `StandardHuffman.py`

## Notes
This is a Python-based algorithmic compression project and does not require an external framework.
